# Hola Mundo desde un Archivo Real .md

Este texto está siendo leído directamente desde un archivo físico guardado en la carpeta `assets` de la aplicación.

## Ventajas de este método:
1. **Código Limpio:** El código de Jetpack Compose no se mezcla con el texto.
2. **Modularidad:** Puedes editar tus man pages de Linux de forma independiente.

## Prueba de código
``` bash
cat /assets/hola_mundo.md
```
